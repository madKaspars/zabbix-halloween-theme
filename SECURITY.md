# Security policy

This development preview has no guaranteed security support period or response time. Updates and responses are voluntary; see [DISCLAIMER.md](DISCLAIMER.md).

If the repository’s Security tab offers **Report a vulnerability**, use that private reporting channel. Otherwise, open a non-sensitive issue asking the maintainer to arrange a private reporting channel. Do not publish credentials, exploit details, private monitoring data, or information that could expose an operational system.

Include affected versions, the impact, and a minimal reproduction using synthetic data when a private channel has been established. Do not test against systems you do not own or have permission to assess.

For vulnerabilities in Zabbix itself, follow [Zabbix’s security policy](https://www.zabbix.com/security_policy).
