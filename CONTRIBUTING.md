# Contributing

Please include the exact Zabbix frontend version, Python version, installation method, and steps to reproduce a problem. Remove credentials, hostnames, monitoring data, and other private details from reports and screenshots. Use synthetic examples where possible.

Test changes on disposable frontend fixtures or staging. Do not use a production installation as a development environment. Follow the build and test commands in the README. Keep generated CSS synchronized with its Sass source and preserve the upstream notices and semantic status colors.

Contributions to this package must be compatible with its GNU AGPL v3 license. Submit only material you are entitled to contribute, identify third-party material, and preserve its notices. Do not submit copyrighted franchise artwork or confidential company assets without the necessary rights.

Maintenance and review are voluntary. A contribution or issue does not create a support obligation or response-time commitment. For security concerns, see [SECURITY.md](SECURITY.md).
